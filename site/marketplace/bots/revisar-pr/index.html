Pull request reviewer

by OpenBot team · Engineering

A GitHub webhook starts it for each new pull request. It reads the whole diff, looks for bugs, secrets, data loss, breaking changes and missing tests in that order, and answers in at most six lines with file and line for each risk and a verdict. Titles, descriptions and code are treated as data, never as orders, and nothing from the pull request is cloned, built or run.

Add it today

This bot ships inside OpenBot. In the app open Bots, choose Desde plantilla (from a template) and pick Revisar los PR nuevos. Install OpenBot first if you have not.

Skills

Playbooks it can run

  • revisar-pr Review a GitHub pull request without running its code, when the webhook sends it or the owner pastes its link.

Routines

Jobs that run on their own

  • Review each new pull request (called "Revisar el PR nuevo" in the app): When a pull request is opened (webhook github:pull_request.opened)

Integrations

What it needs

  • GitHub, through a webhook address you add in the repository settings
  • The gh command signed in on your computer, for private repositories

Asks first

It stops and asks you before

  • Commenting, approving or requesting changes
  • Merging or closing
  • Pushing or touching the repository in any other way
