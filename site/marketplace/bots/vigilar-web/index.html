Web watcher

by OpenBot team · Personal

Tell it which page to watch and, if you care about one part (a price, a list), which. It keeps the last copy of each page and compares. An error, a captcha or a login page never replaces the saved copy. When nothing changed it answers with a single quiet line.

Add it today

This bot ships inside OpenBot. In the app open Bots, choose Desde plantilla (from a template) and pick Vigilar una web y avisar si cambia. Install OpenBot first if you have not.

Skills

Playbooks it can run

  • vigilar-web Watch the pages the owner gives, compare them with the last copy and report only what changed.

Routines

Jobs that run on their own

  • Check the watched pages (called "Vigilar la web" in the app): Every day at 09:00

Integrations

What it needs

  • OpenBot's browser

Asks first

It stops and asks you before

  • Starting a purchase or booking
  • Filling in or sending forms
  • Accepting terms or creating an account
  • Downloading files
