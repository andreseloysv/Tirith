Everything a helper should do

Install OpenBot

One line in a terminal. The installer checks the release's signature and each file's checksum before it puts anything on your computer.

Desktop app for macOS0.2.1 for Apple silicon (.dmg). This version still shows the old name, Tirith. All releasesSigned builds for macOS and Linux, x86_64 and arm64 Source codeMIT license, on GitHub

  1. Open Terminal

    Press ⌘ Space, type Terminal and press Return.

  2. Run the installer

    curl -fsSL https://github.com/andreseloysv/Tirith/releases/latest/download/install.sh | sh

    It puts tirith in ~/.local/bin and starts a short guide.

  3. Connect your agents

    Pick the agents you use: the Anthropic CLI, OpenAI Codex, GitHub Copilot or Muse Code. For each, the guide runs its maker's installer, opens its sign-in and checks that it answers.

  4. Open OpenBot

    Go to 127.0.0.1:7717 in your browser. The + under the faces makes your first bot. If the page says this browser is not signed in, run:

    ~/.local/bin/tirith open

  5. Keep it on (optional)

    Answer yes when the guide asks to run OpenBot as a service, so your routines run while you are away. Always on, step by step.

  1. Run the installer on your server

    curl -fsSL https://github.com/andreseloysv/Tirith/releases/latest/download/install.sh | sudo sh -s -- --server

    With sudo, OpenBot runs as its own user, tirith, never as root, and starts at boot with systemd. On a desktop, run it without sudo and --server.

  2. Connect your agents

    Each sign-in shows a link and a code, so it works over SSH. The guide installs each agent from its maker and checks that it answers.

  3. Reach the page from your computer

    ssh -N -L 7717:127.0.0.1:7717 you@your-server

    Leave that running and open http://127.0.0.1:7717/ in your browser. If the page says this browser is not signed in, run this on the server and open the link it prints within 10 minutes:

    tirith open link

  4. Check everything

    tirith doctor

    It lists every part and how to fix what is missing.

  1. Install WSL with Ubuntu

    Open PowerShell as administrator and run:

    wsl --install -d Ubuntu

    Restart when asked, then open Ubuntu from the Start menu and choose a user name and password.

  2. Run the installer in Ubuntu

    curl -fsSL https://github.com/andreseloysv/Tirith/releases/latest/download/install.sh | sh

    It installs tirith in ~/.local/bin and starts the guide.

  3. Connect your agents

    Answer the guide as on Linux. Each sign-in shows a link and a code to open in your Windows browser.

  4. Open OpenBot in Windows

    Go to http://127.0.0.1:7717/ in Edge or Chrome: WSL 2 passes it through to Windows. If the page says this browser is not signed in, run this in Ubuntu and open the link it prints:

    ~/.local/bin/tirith open link

There is no native Windows version yet: OpenBot runs inside WSL 2, Microsoft's Linux for Windows, and needs it running while your bots work.

FAQs

How is OpenBot different from Grok Bot, Muse, Dots and Duet?

They run your bots on their maker's computers, with their maker's models, inside their maker's subscription. OpenBot runs on your own computer, lets you choose the agent and model for each job, and is open source. The table above has the details.

Which agents does it work with?

The Anthropic CLI, OpenAI Codex, GitHub Copilot and Meta's Muse Code, each with the account you sign in with. You choose agent, model and effort per role, with a fallback for when one runs out of credits.

Does my computer have to stay on?

Yes: your bots work where OpenBot runs. It can run as a service that starts by itself, on a Mac even with nobody logged in. A Mac mini or a small Linux server works well.

Can I use it from my phone?

Yes. Scan the QR code on the Rooms page and your phone gets a chat with every bot and project, end-to-end encrypted through agentsmessenger.com, with nothing to install.

Will a bot buy or send things without me?

Every bot is told to ask before it sends, buys, deletes or publishes, and a judge model reviews its turns afterwards and flags anything that had no approval. That is an instruction, not a lock, so give each bot only the accounts it needs.

Where does my data go?

OpenBot keeps its state on your computer, and its page never listens on the network. What your agents send to their models follows each provider's terms. Everything OpenBot starts reaches the network through its own proxy, which records every destination.

Does it work on Windows?

Through WSL 2, as on Linux; see the Windows steps above. There is no native Windows version yet.
