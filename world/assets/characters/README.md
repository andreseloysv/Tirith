# Character models

Drop one GLB per class here and the world uses it automatically instead of the
procedural placeholder hero:

`steward.glb`, `stonewright.glb`, `loremaster.glb`, `warden.glb`,
`swiftrider.glb`, `herald.glb`, `glasswright.glb`, `archivist.glb`

Requirements (see `../../../docs/LORE.md`): stylized heroic proportions, 8k–25k
triangles, PBR textures up to 2K, Y-up, metres, facing +Z, feet at origin.
Rigged humanoid with an `AnimationPlayer`; clips are matched by name
(case-insensitive substring): `idle`, `work`, `celebrate`, `fail`, `walk`.
