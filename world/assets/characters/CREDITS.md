# Character models

All three are CC0 models published in the Meshy community, prepared for the citadel with
`tools/art/prep_character.py` (decimated to ≤ 25k triangles, grounded, 1.3 m tall, textures ≤ 2K;
the stonewright's display base was removed). Static meshes: no rig, no animations yet.

| File | Class | Source | Author | Licence |
|---|---|---|---|---|
| `warden.glb` | Warden | Meshy community post "Iron Dwarf" (https://www.meshy.ai/posts/019bbed6-1d0c-7383-be0a-1b827edb60d7) | elboudai | CC0 |
| `stonewright.glb` | Stonewright | Meshy community post "Warrior Dwarf" | celticgypsy69 | CC0 |
| `herald.glb` | Herald | Meshy community post "Dwarf Warrior" | Nick | CC0 |
