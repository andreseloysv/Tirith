# Credits

Everything in `world/` is original work created for Tirith during the hackathon:

- All 3D geometry is generated in code (`scripts/mats.gd`, `scripts/hero.gd`,
  `scripts/world_builder.gd`) — no third-party models, textures or fonts.
- `visual-plan/refs/hero.jpg` is an AI-generated art-direction reference made
  for this project; it is not shipped in the game.
- The engine is [Godot Engine](https://godotengine.org) 4.7 (MIT licence).
- The default font is Godot's bundled font.
- Character GLBs in `assets/characters/` (warden, stonewright, herald) are
  CC0 models credited in `assets/characters/CREDITS.md`.
